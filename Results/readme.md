# Experimental results

These files collect the figures and comparison tables from the thesis experiments.

| File | Contents |
| --- | --- |
| [Segmentation results](Figures/Segmentation_Results.pdf) | Examples of energy, gradient and Doppler segmentation |
| [Training curves](Figures/Training_Curves.pdf) | Training and validation behaviour |
| [ROC curves](Figures/ROC_Curves.pdf) | Classification performance across thresholds |
| [Confusion matrices](Figures/Confusion_Matrices.pdf) | Valid-kick and invalid-motion classification results |
| [Method comparison tables](Performance-Tables/Method_Comparison_Tables.pdf) | Comparison of segmentation methods and window lengths |

The thesis reports the most consistent performance with Doppler segmentation and a 2000-sample window. See the [full report](../Report/Project_Thesis.pdf) for the experiment context and discussion.

These are archived results, not outputs from a new run. The supplied code's defaults and evaluation limitations are described in the [reproduction notes](../README.md#reproducing-the-reported-results). Use those notes when comparing a new run with the reported figures.
